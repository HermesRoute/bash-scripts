# bash-scripts
This repository contains a collection of **Bash scripts** created to automate tasks, streamline workflows, and deepen my understanding of Linux, Unix tools, and shell scripting.

The focus is on **practical system-level automation**, clarity, and leveraging standard Unix utilities effectively.

## Purpose of This Repository

- Improve Bash scripting skills through hands-on practice
- Automate repetitive or error-prone tasks
- Build small, composable utilities
- Explore Linux internals and command-line tooling
- Develop a personal library of reusable scripts

This repo serves as both a learning workspace and a toolbox.

## What You’ll Find Here

Scripts may cover topics such as:
- System administration tasks
- File and directory management
- Permissions, users, and processes
- Networking and connectivity checks
- Linux diagnostics and monitoring
- Automation and scheduling helpers
- Shell experiments and patterns
- Wrappers around standard Unix tools (`grep`, `awk`, `sed`, `find`, etc.)

Scripts range from quick one-liners expanded into files, to more structured and documented utilities.

## Repository Structure

Scripts are generally organized by purpose or category:
```
bash-scripts/
├── system/
├── networking/
├── automation/
├── utilities/
└── README.md
```
Some scripts may be standalone; others may evolve over time as they are refined or extended.

## Work in Progress

This is an active learning repository.

- Older scripts may be refactored or simplified
- Not all scripts are designed for production use

Iteration and improvement are intentional.
